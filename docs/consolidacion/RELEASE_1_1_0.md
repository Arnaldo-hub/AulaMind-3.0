# Objetivo

Consolidar el nuevo núcleo de acceso al Currículum Nacional.

Esta versión introduce oficialmente el Curriculum Repository como el único punto de acceso al dominio curricular de AulaMind Enterprise.

A partir de esta versión ningún módulo deberá acceder directamente a los documentos curriculares.

Toda consulta deberá realizarse mediante CurriculumRepository.
