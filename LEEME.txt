AULAMIND ENTERPRISE 3.0 — SELECTOR OA/AE INTERACTIVO PARA PIE
Fecha del paquete: 3 de noviembre de 2026

IMPORTANTE
Este paquete reemplaza a “aulamind_correccion_pie_curricular.zip” y a “aulamind_mejora_presentacion_pie.zip”. No apliques los tres: utiliza solamente esta versión, que ya incorpora las correcciones anteriores.

COMPORTAMIENTO SOLICITADO
- La lista desplegada muestra solamente los códigos: OA 1, OA 2, OA 3, etc.; también admite AE.
- Al pasar el mouse sobre un código, el rectángulo azul muestra su código y descripción oficial completa.
- La lista y el rectángulo no se superponen: ambos permanecen visibles durante la revisión.
- Al hacer clic, el código queda seleccionado y visible en el campo.
- El formulario envía “código — descripción completa” al generador PIE.
- También funciona con teclado: flechas para revisar, Enter para seleccionar y Escape para cerrar.
- Ya no se utiliza el desplegable nativo que mostraba descripciones gigantes ni tooltips poco fiables.

ARCHIVOS INCLUIDOS
1. routes/planning.py
   Mantiene el catálogo curricular compartido entre PIE y Planificaciones.

2. static/js/pie.js
   Implementa el selector OA/AE personalizado, la vista previa al pasar el mouse, la selección con mouse y teclado, la limpieza al cambiar de unidad y el envío del objetivo completo.

3. templates/pie.html
   Contiene el botón selector, la lista de códigos, el rectángulo de descripción y los estilos que impiden el desbordamiento. Renueva pie.js a la versión pie-curriculum-20261103-v3.

NO SE MODIFICÓ
Ningún JSON ni descripción curricular. Tampoco se modificaron base de datos, usuarios, autenticación, planes, persistencia, historial, exportación, variables de entorno, GitHub, Render o producción.

INSTALACIÓN LOCAL
1. Cierra la aplicación local.
2. Respalda los tres archivos actuales.
3. Descomprime este ZIP.
4. Copia routes/planning.py, static/js/pie.js y templates/pie.html a la raíz del repositorio, conservando las carpetas y reemplazando los archivos.
5. Ejecuta la aplicación y abre /pie.

PRUEBA PRINCIPAL
1. Selecciona 4° Medio.
2. Selecciona Ciencias de la Salud.
3. Selecciona Conocimiento y comprensión.
4. Abre Objetivo de Aprendizaje: deben aparecer solamente OA 1, OA 2, OA 3, OA 4 y OA 5.
5. Pasa el mouse sobre OA 2: el rectángulo debe mostrar el código OA 2 y su descripción, sin textos gigantes ni contenido fuera de pantalla.
6. Prueba los demás códigos y verifica que cada uno muestre su propia descripción.
7. Selecciona uno con clic y confirma que el campo conserva el código.
8. Repite usando flechas y Enter.

OTRAS COMPROBACIONES
- Cambiar de unidad limpia la selección y descripción anterior.
- Duplicados exactos se omiten; unidades distintas que solo comparten número no se fusionan.
- No hay desbordamiento horizontal en 375, 768, 1024 y 1440 píxeles.
- El valor FormData conserva código y descripción completa.
