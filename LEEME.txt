AULAMIND ENTERPRISE 3.0 — CORRECCIÓN CURRICULAR DEL MÓDULO PIE
Fecha del paquete: 3 de noviembre de 2026

PROPÓSITO
Corregir el módulo Adecuaciones Curriculares PIE para que disponga del mismo catálogo curricular que Planificaciones y para que el selector de objetivos sea legible.

ALCANCE DEL PAQUETE
Contiene solamente estos tres archivos de aplicación:

1. routes/planning.py
   - El endpoint compartido de asignaturas consulta primero CurriculumService en todos los niveles.
   - La lista histórica de asignaturas queda únicamente como respaldo.
   - Solo se exponen asignaturas con contenido curricular utilizable.
   - PIE y Planificaciones reciben cursos, asignaturas, unidades y OA/AE desde la misma API.

2. static/js/pie.js
   - El desplegable muestra solamente el código del OA/AE.
   - El valor enviado por el formulario conserva “código — descripción completa”.
   - Al seleccionar un objetivo, su texto completo aparece en un recuadro legible.
   - Al cambiar curso, asignatura o unidad, se limpia el detalle anterior.

3. templates/pie.html
   - Ajusta el ancho del selector para evitar desbordamientos.
   - Agrega el recuadro de descripción completa del objetivo.
   - Renueva la versión de pie.js para impedir que el navegador reutilice el script anterior.

No se incluyen JSON curriculares, templates/mineduc.html ni cambios de base de datos, autenticación, usuarios, planes, persistencia, exportación, variables de entorno o configuración de Render.

REQUISITO PREVIO
Aplicar este paquete sobre una copia del repositorio que ya contenga la actualización curricular integral entregada anteriormente. Si esa actualización todavía no está aplicada, debe incorporarse primero; este paquete PIE no vuelve a incluir sus 129 archivos JSON ni el selector de Planificaciones.

INSTALACIÓN PARA REVISIÓN LOCAL
1. Cerrar la aplicación local si está ejecutándose.
2. Hacer una copia de seguridad de los tres archivos actuales del repositorio.
3. Descomprimir este ZIP.
4. Copiar routes/planning.py, static/js/pie.js y templates/pie.html a la raíz del repositorio, conservando exactamente sus carpetas y reemplazando los archivos correspondientes.
5. Ejecutar la aplicación localmente con el procedimiento habitual del proyecto.
6. Abrir el módulo PIE y revisar las pruebas indicadas abajo.

PRUEBAS RECOMENDADAS EN /pie
1. Comprobar que el listado de cursos y asignaturas coincide con el disponible en Planificaciones.
2. Revisar especialmente Inglés de 1° a 4° básico.
3. Recorrer varias unidades y confirmar que aparecen sus OA/AE.
4. Seleccionar un OA y comprobar que:
   - El desplegable muestra el código, sin extenderse con toda la descripción.
   - El recuadro inferior presenta el código y la descripción completa.
   - El texto puede leerse sin cortes ni desbordamiento horizontal.
5. Repetir la prueba con un AE de Lengua Indígena y confirmar que sigue identificado como AE.
6. Cambiar de unidad, asignatura y curso; el recuadro de descripción debe limpiarse.
7. Generar una adecuación de prueba y confirmar que el objetivo utilizado contiene código y descripción completa.
8. Revisar brevemente Planificaciones para confirmar que su carga curricular sigue funcionando.
