CONTENIDO

- data_curricular: 129 JSON actualizados (110 modificados y 19 nuevos).
- templates/mineduc.html: selector que muestra el código del OA/AE y conserva la descripción completa.

No se incluyen cambios en Python, base de datos, usuarios, planes, variables de entorno ni otras funciones.

1. REVISIÓN LOCAL

1. Haz una copia de seguridad de tu repositorio local.
2. Abre una terminal en la carpeta del repositorio y ejecuta: git pull
3. Extrae este ZIP en una carpeta independiente para revisarlo.
4. Copia las carpetas data_curricular y templates del paquete a la raíz del repositorio. Acepta reemplazar los archivos existentes correspondientes.
5. Ejecuta AulaMind localmente como lo haces habitualmente e ingresa a /mineduc con una cuenta de prueba autorizada.

No copies documentos PDF ni archivos de auditoría a la aplicación; el paquete solo contiene los archivos finales y este instructivo/informe.

2. COMPROBACIONES RECOMENDADAS EN LA PANTALLA

- Selector de OA/AE: la lista desplegable muestra códigos; al seleccionar uno, el campo informativo y el valor utilizado contienen el código y la descripción completa.
- 1° Básico → Inglés → Unidad 1: deben aparecer los OA con textos completos.
- 6° Básico → Inglés → Unidades 3 y 4 → OA 12: el último ejemplo debe incluir «there is/are…».
- 4° Básico → Educación Física y Salud → Unidad 4 → OA 10: debe terminar en «organizar equitativamente los equipos.»
- 6° Básico → Lengua y Cultura de los Pueblos Originarios Ancestrales, programa Colla: cuatro unidades con 4, 3, 3 y 4 OA.
- 7° Básico, Mapuzugun: AE 1–16; 8° Básico, Quechua: AE 1–13. No deben renombrarse como OA.
- 2° Medio → Ciencias Naturales: doce unidades y OA 1–18.
- 3° o 4° Medio → Teatro → Unidad 3 → OA 3: debe terminar en «considerando un público específico.»
- 3° o 4° Medio → Mundo Global → OA 7: debe decir «problemas presentes a nivel local».

Revisa también otros cursos y asignaturas que uses habitualmente. El informe contiene el detalle completo de los 129 archivos.

3. SUBIR A GITHUB

Después de comprobar el resultado local, desde la raíz del repositorio:

git status
git add data_curricular templates/mineduc.html
git commit -m "Actualizar bases curriculares y selector de OA"
git push origin main

Antes del commit, confirma con git status que solo se incluyan los archivos curriculares y la plantilla indicados. Si tu rama principal tiene otro nombre, utiliza esa rama en git push.

4. REVISAR RENDER

- Si Render tiene despliegue automático, espera que termine el despliegue del nuevo commit.
- Si no, abre el servicio correspondiente y usa Manual Deploy → Deploy latest commit.
- Revisa que el despliegue termine sin errores y repite las comprobaciones de /mineduc en el entorno de revisión o producción que utilices.

El paquete está validado localmente, pero GitHub y Render deben comprobarse después de tu carga y despliegue. No se han modificado directamente esos servicios.
